# DRAFT report evidence package

This directory is intentionally a draft support package, not an approved academic report. It must be completed with verified university metadata, genuine supervisor review, actual user-study evidence and faculty-required signatures before submission.

`DRAFT_REPORT.md` now supplies a six-chapter implementation-based draft and
`source-register.md` records the traceable public sources used for context.
Use the implementation ledger, architecture/database/security/recommendation
documents, real test evidence and source register when refining it. Do not
invent participant numbers, approvals, citations or deployment results.
